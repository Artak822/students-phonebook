# АСПиРС CRM — что реализовано в системе

---

## Вход в систему

- Авторизация по логину и паролю
- При первом входе обязательная смена пароля — до её выполнения доступ к системе закрыт
- При истечении сессии — автоматический редирект на страницу входа
- Защита от перебора: не более 10 попыток входа за 5 минут

## Студенты

### Список студентов
- Таблица со всеми студентами: фото (или инициал), ФИО, телефон, учебная группа, номер комнаты, дата рождения и возраст
- Значок «несов.» у студентов младше 18 лет
- Красный контур вокруг аватара у студентов, которые сейчас болеют
- Поиск по ФИО и номеру телефона одновременно
- Фильтр по учебной группе
- Фильтр по корпусу
- Кнопка «Больные» — показывает только студентов с активной болезнью
- Пагинация по 50 записей

### Карточка студента
- ФИО
- Телефон в формате +7 (___) ___-__-__
- Учебная группа с поиском по названию; прямо из формы можно создать новую группу
- Дата рождения с отображением возраста; автоматический маркер «несовершеннолетний»
- Фото: загрузка (JPEG, PNG, WebP до 5 МБ), просмотр, удаление
- Комната: назначение с умным поиском (можно набрать компактно — `814361`), кнопка сброса
- Заметки в свободной форме
- Значок «✕» у имени, если студент сейчас болеет

### Заявления об отсутствии
- Список всех заявлений студента с датой и временем начала и конца
- Создание заявления: дата+время начала, дата+время конца (необязательно)
- Удаление заявления

### Болезни
- Статус «Здоров» с кнопкой «Заболел»
- **Фиксация болезни**: дата начала, временная комната (опционально), первичная запись о состоянии (опционально)
- **Активная болезнь**: пульсирующая красная точка, длительность в днях, временная комната с возможностью изменить её прямо в карточке, хронологический список записей
- **Добавление записи**: дата и текст наблюдения — для ежедневного отслеживания состояния
- **Выздоровление**: дата выздоровления, финальная запись (опционально)
- **История болезней**: список прошлых болезней в виде аккордеона — период, длительность, количество записей; при раскрытии — полный таймлайн с временной комнатой
- Последняя точка таймлайна: красная у активной болезни, зелёная у завершённой
- Удаление болезни (со всеми записями) — доступно через развёрнутую карточку
- Временные комнаты для болезней — только одноместные (вместимость 1)

### История изменений студента
- Полный лог всех изменений карточки: что изменилось, старое и новое значение, кто из администраторов изменил, когда

## Комнаты

### Список комнат
- Таблица с комнатами: корпус, подъезд, номер, вместимость, количество жильцов
- Поиск по номеру комнаты (в том числе компактный ввод: `814361`)
- Фильтр по корпусу и подъезду
- Создание комнаты прямо в списке
- Редактирование параметров комнаты
- Удаление комнаты (невозможно, пока в ней есть жильцы)
- Массовое создание комнат для целого подъезда

### Карточка комнаты
- Адрес в формате `корпус-подъезд-номер` (например `8-1-361`), вместимость, статистика заполненности
- Список жильцов с фото/инициалом и ссылкой на карточку каждого студента
- **Добавить жильца**: поиск по ФИО и телефону прямо в карточке комнаты, выбор из выпадающего списка — студент уже в комнате сразу
- **Выселить жильца**: кнопка напротив студента → подтверждение → студент отвязан от комнаты
- **Переселить жильца**: выбор новой комнаты с поиском → студент переведён без лишних переходов
- Проверка вместимости: система не позволяет заселить больше людей, чем позволяет комната

## Администраторы

- Список всех администраторов: имя пользователя, ФИО, роль, статус активности
- Создание администратора с назначением роли
- Редактирование данных и роли
- Деактивация / удаление (нельзя удалить себя, нельзя удалить последнего суперадминистратора)

---

## Роли и права

- Список ролей с описанием
- Создание и редактирование ролей
- Гибкое управление набором прав: просмотр/редактирование/удаление студентов, комнат, администраторов, ролей, назначение комнат
- Системные роли защищены от изменения
- Нельзя удалить роль, пока она назначена хотя бы одному администратору

---

## Учебные группы

- Создание групп прямо из карточки студента
- Поиск по названию при вводе
- Нельзя удалить группу, в которой есть студенты

---

## Общее

- Разграничение доступа: каждый администратор видит и может делать только то, что разрешает его роль
- Все данные студентов защищены — доступ только для авторизованных пользователей с нужными правами
- Мягкое удаление студентов: данные не уничтожаются, карточка архивируется
- История изменений по каждому студенту сохраняется автоматически
